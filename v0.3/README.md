# Black Oath v0.3

Versão jogável mobile com Juramentos, Relíquia Lua Negra, Familiar Corvo de Carniça, Corrupção, Caçadas, Duelo contra bots, reorganização do tabuleiro, salvamento local e chefe final Rei sem Sombra.

Esta pasta contém a versão usada pelo workflow do GitHub Actions para gerar o APK Android. Os arquivos `game.js` e `style.css` são reconstruídos durante o build a partir de `parts/`.

Os quatro cenários grandes são reaproveitados do pacote v0.2 já presente no repositório para evitar duplicar cerca de 11 MB de imagens.
